Settings

Bring your own keys. TMDB preferences stay in this browser. LLM keys last for the current session unless you explicitly choose to remember them, and are never committed to the repository.

TMDB API Key Not set

Required to browse movie data. Get a free key at themoviedb.org. If the server already has a TMDB_API_KEY in its .env, this is optional.

LLM Narrator (bring your own) Not set

Optional. Adds an AI-written "why this recommendation" reason to each pick. Use any OpenAI-compatible chat endpoint (OpenAI, Ollama's /v1, vLLM, LM Studio, etc.). Leave blank to skip — recommendations work without it.

Your key is sent per-request to your configured BERT gateway and is not stored on the server. Public deployments reject local/private LLM URLs; enable LUMITRACE_ALLOW_PRIVATE_LLM=true only for a self-hosted BERT process.

BERT Service URL Server default

Advanced. Overrides the server's REMOTE_SEARCH_URL so you can point semantic search at your own BERT service. Leave blank to use whatever the server has in its .env.

The override only works if the operator has not set LOCK_REMOTE_SEARCH_URL=true on the server (public deployments should lock it to prevent the server from forwarding to arbitrary hosts).

The server has locked the semantic target. Your browser cannot redirect requests to another host.
