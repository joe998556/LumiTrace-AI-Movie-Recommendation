Three-minute setup

From APK to your first recommendation.

No server address, model download, Python environment, or LumiTrace account is required. You need Android 7.0 or newer, internet access for TMDB, and your own TMDB API key.

01
Install

Download the official APK.

Download the latest signed build from GitHub Releases. If Android asks, allow your browser or file manager to install this one app, then continue through the normal package installer.

Download LumiTrace.apk↓ View release notes →
Optional checksum check

On Windows, run Get-FileHash .\LumiTrace.apk -Algorithm SHA256 and compare the value with LumiTrace.apk.sha256 attached to the same release.

02
Connect TMDB

Create your personal API key.

Sign in to TMDB, open API settings, and request an API key under the provider's current process. LumiTrace uses the TMDB API v3 key to retrieve movie discovery, search, details, and posters directly from your phone.

Open TMDB API settings↗
Your key is not bundled with the APK

Every user supplies their own key. Do not post it in an issue, screenshot, source file, or public build log.

03
Start tracing taste

Save the key and rate what you watched.

  1. 1

    Open LumiTrace and tap the sliders icon in the top-right corner.

  2. 2

    Open the TMDB section, paste the API v3 key, and save it.

  3. 3

    Return home, browse or search for films, and mark at least one as watched.

  4. 4

    Add a 1-10 rating when possible, then open Recommend. More ratings produce a clearer local taste profile.

Recommendation scope

What happens locally?

The APK includes a 1,000-film MovieLens/MiniLM starter index. Watched films represented in that index shape a weighted vector; low ratings suppress similar candidates, and a diversity pass keeps the list from repeating one genre.

Troubleshooting

Common first-run checks.

The home screen still asks for a TMDB key.

Confirm that you saved the API v3 key, not a read-access token with extra text. Remove leading or trailing spaces and retry on a working internet connection.

I can browse movies but recommendations are limited.

The live TMDB catalog is broader than the bundled 1,000-film semantic index. Mark several recognizable films as watched and add ratings. The app reports when it falls back to metadata signals.

Android warns that the app was not installed from Play.

This is expected for a GitHub-distributed APK. Keep Play Protect enabled, install only the release asset from this repository, and compare the published checksum when you want an additional integrity check.

I want to remove everything.

Use Android Settings > Apps > LumiTrace > Storage > Clear data, or uninstall the app. Android cloud backup is disabled.
