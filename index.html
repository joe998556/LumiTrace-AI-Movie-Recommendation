From zero to useful

The old server setup is gone. LumiTrace is now designed for the person holding the phone, not the person maintaining infrastructure.

01

Install the APK

Download the latest signed release from GitHub and install it on Android 7.0 or newer.

02

Add your TMDB key

Paste your own TMDB API key once in Settings. It is stored in app-private storage on your phone.

The application

A movie journal with a recommendation engine underneath.

01 / Local recommendation

Your ratings change the result.

High scores strengthen related semantic and genre signals. Low scores suppress candidates that resemble what did not work for you. The final list is diversified before it reaches the screen.

How the AI works

The expensive model work is already done.

The APK carries a compact, precomputed MovieLens/MiniLM starter index. At recommendation time the phone performs vector lookup, a weighted taste profile, exact similarity scoring, low-rating penalties, and diversity re-ranking. It does not run a Transformer or contact a LumiTrace backend.

Private by architecture

Your movie history is not a LumiTrace account.

There is no LumiTrace login, cloud profile, analytics collector, or recommendation server. Android backup is disabled. Clearing app data removes the local profile.
