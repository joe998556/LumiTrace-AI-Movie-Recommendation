Privacy boundary

A movie profile, not another cloud account.

LumiTrace does not operate an account, analytics, synchronization, or recommendation backend. Core taste ranking is calculated inside the Android app.

Stays in app-private storageViewing profiles, watched films, favorites, ratings, notes, feedback, queue, events, and recommendation inputs
Sent directly to TMDBMovie discovery, search, detail, and image requests made with the personal TMDB key
Sent only after explicit setupTrakt history and rating sync using credentials supplied by the user
Not collected by LumiTraceAccounts, email addresses, analytics identifiers, ad profiles, server-side taste history, and crash telemetry
Local storage

Protected by Android's app boundary.

LumiTrace requests encrypted preferences backed by Android Keystore. If encrypted preferences cannot be initialized on a device, the current build falls back to Android app-private preferences rather than exporting data. Android cloud backup is disabled in the manifest.

User control

Delete or move your profile.

The app can export and import taste data without including API credentials. Clearing app data or uninstalling LumiTrace removes its local profile. A user should inspect any exported file before sharing it.

Provider-by-provider

External data flows are narrow and visible.

TMDB

Required for the normal browsing experience. Requests go from the phone to `api.themoviedb.org` over HTTPS with the key entered in Settings. TMDB's own terms and privacy practices apply.

Trakt

Optional. Device authorization, import, and upload occur only after the user enters credentials for a Trakt API application and invokes a sync action. Disconnecting can remove locally stored Trakt credentials and tokens.

GitHub

The release APK does not contact GitHub during normal use. GitHub is only the distribution source selected by the user.

Limits

What local-first does not promise.

A compromised device can expose app data.

Root access, malicious accessibility services, screenshots, clipboard capture, or a compromised operating system are outside LumiTrace's protection boundary.

A provider can observe requests sent to it.

TMDB and explicitly enabled providers receive the requests needed to deliver their service. Local recommendation prevents LumiTrace from collecting taste history; it does not make third-party network calls invisible to those providers.

Sideloading is not an app-store review.

Install only release assets published by this repository, retain Android security scanning, and verify the attached checksum when appropriate.

Inspectable by design

Build it, audit it, or install it.

The Android source, recommendation weights, tests, bundled-index notice, and release checksum are public in this repository.
